# Repository guidelines

- HTML files must be created under `./docs`.
- Whenever an HTML page is added, add a link to its published page in `README.md`.
- When a directory contains multiple HTML pages, represent their hierarchy with nested lists in `README.md`. Use the directory's `index.html` link as the parent item and list the other pages beneath it. If there is no `index.html`, use the directory name as the parent item. Nest subdirectories in the same way.
- Published URLs use `https://svjunic.github.io/github-pages/` as their base URL.
- For example, `docs/aria-current-auto-toggle/index.html` is published at `https://svjunic.github.io/github-pages/aria-current-auto-toggle/`.
