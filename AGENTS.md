# Repository guidelines

- HTML files must be created under `./docs`.
- Whenever an HTML page is added, add a link to its published page in `README.md`.
- Published URLs use `https://svjunic.github.io/github-pages/` as their base URL.
- For example, `docs/voiceover/index.html` is published at `https://svjunic.github.io/github-pages/voiceover/`.
